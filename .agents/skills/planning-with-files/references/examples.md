# Examples: Planning with Files

## Research task

1. Create `task_plan.md`
2. Search and write discoveries to `findings.md`
3. Re-read the plan before synthesizing
4. Record delivery steps in `progress.md`

## Bug fix task

1. Capture the bug and reproduction in `task_plan.md`
2. Log relevant code paths and hypotheses in `findings.md`
3. Record each failed attempt in `progress.md`
4. Change approach instead of retrying the same failed action

## Feature work

1. Split work into phases
2. Track design decisions in `task_plan.md`
3. Keep implementation notes in `progress.md`
4. Keep external research and references in `findings.md`
